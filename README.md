# Python Logical Operators

## Explanation

Logical operators are used to combine or reverse conditions in Python. They return a Boolean value: `True` or `False`.

Python provides three main logical operators:

* `and`
* `or`
* `not`

## Problem Statement

Write a Python program that accepts two numbers and demonstrates the use of logical operators with comparison conditions.

## Features

* Accepts two numbers from the user
* Uses `and`, `or`, and `not`
* Demonstrates Boolean expressions
* Displays the results of logical operations

## How It Works

The program compares the two input numbers and combines the conditions using logical operators.

* `and` returns `True` when both conditions are true.
* `or` returns `True` when at least one condition is true.
* `not` reverses the Boolean result.

## Technologies Used

* Python 3

## Program Flow

1. Start the program.
2. Read two numbers.
3. Create comparison conditions.
4. Apply `and`, `or`, and `not`.
5. Display the results.
6. End the program.

## Sample Input

```text
Enter first number: 10
Enter second number: 20
```

## Sample Output

```text
AND: False
OR: True
NOT: True
```
